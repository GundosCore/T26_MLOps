## Ответственность и подтверждение вклада

| Роль | За что отвечает | Чем подтверждается вклад |
|---|---|---|
| Repository administrator | Доступ к репозиторию, правила защиты `main`, шаблоны issue и pull request | Снимок или экспорт правил и проверяемый PR |
| Environment engineer | Версия Python, установка зависимостей, чистый запуск проекта | Изменение README, `.python-version` или сценария установки |
| Quality Engineer | Автоматические проверки: ruff, pytest, CI | Запуск workflow, тест или исправление проверки |
| Release lead | План работы, связь issue и PR, контрольная точка `lr1-v1` | Закрытая issue, merge или release notes |
| Documentation and risk reviewer | Записи решений, правила работы, риски | Документ, содержательное review или запись решения |

## Тимлид

Тимлид — функция в процессе сдачи, а не отдельная роль. По схеме преподавателя тимлид ведёт общий репозиторий команды, принимает pull request участников и отправляет готовую работу в репозиторий преподавателя. В нашей команде тимлид — Станислав Соловцов.
